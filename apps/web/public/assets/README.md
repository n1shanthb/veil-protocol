# Asset use
All SVGs here are original vector design-reference assets, supplied for Veil implementation. Use the approved mark consistently; do not replace with generic Angular or shield logos. Wordmark text remains editable; use Space Grotesk or convert to paths after the actual font is available. Icon SVGs use currentColor; inline them or use equivalent Lucide icons with 1.6–1.8px strokes. No third-party font files are bundled. Illustration geometry is decorative, not a proof diagram; keep aria-hidden. Merkle diagram is simplified and not a specification of LeanIMT tree shape.
